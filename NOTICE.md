# Third-party notices

This project incorporates ideas and techniques from earlier work in the AMX Mod X
community. Each is credited in the README with a link where one exists.

- **Vampire** (Shalfey, 2007). The healing-on-kill mechanic, reworked here into a
  persistent buff rather than a permanent player state.
- **AmxX Cheats** (DarkGL). The wallhack ESP technique: the marker is projected onto
  the wall the trace hits, because beams occlude against geometry.
- **Rotating DMG 6-dir HUD** (LyesMC). The floating damage number presentation.
- **AdvancedQuakeSounds** (ClaudiuHKS). The announcer sound pack, which this plugin
  looks for but does not bundle. It remains under its own terms:
  https://github.com/ClaudiuHKS/AdvancedQuakeSounds

Everything else, including the rank system, both ladders, the medals, the combo
table, the killfeed, bullet time and the aim rating, is original to this project and
covered by the MIT licence in `LICENSE`.
